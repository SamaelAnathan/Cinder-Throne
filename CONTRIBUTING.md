# Contributing

Contributions are welcome.

## Ground rules

- Keep the setting original.
- Do not submit copyrighted artwork, logos, music, fonts, names or lore from third-party game or entertainment franchises.
- Put balance/content changes in `game-data.js` where possible.
- Keep public-alpha saves backwards compatible where practical.
- Test desktop and narrow/mobile layouts.
- Avoid adding a framework or build dependency without a clear maintenance benefit.

## Suggested contribution areas

- Balance.
- New original sectors.
- New original unit lines.
- Research tree expansion.
- Threat mechanics.
- Accessibility.
- Save migration.
- Automated tests.
